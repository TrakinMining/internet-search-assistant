# Internet Search Assistant (Python Mini Project)

A command-line tool that searches the internet using free public APIs
(Wikipedia and DuckDuckGo), shows readable results in the terminal,
opens links in your browser, and stores a search history in JSON.

**Submitted by:** Keshav Saini (UID: 25BCD10101)
**Submitted to:** Mrs. Preeti, Assistant Professor
**Submission date:** 21 October 2026

## Features
- Search Wikipedia and read a summary of any result
- Quick answers from the DuckDuckGo Instant Answer API
- Open a Google search in the default web browser
- Search history saved to `search_history.json` (view / clear)
- Error handling for network failures and invalid input

## Requirements
- Python 3.8 or later
- `requests` library

## How to run
```
pip install -r requirements.txt
python search_assistant.py
```
